# Nhận thức dược liệu

Web ôn tập dược liệu (nhóm hỗ trợ tiêu hóa, gan mật, bổ dưỡng): tra cứu, trắc nghiệm, tự luận, tạo đề kiểm tra và trò chơi.

- Một file `index.html`, không cần cài đặt hay build.
- Tiến độ không cần lưu, dữ liệu nằm trong biến `R` ở đầu phần `<script>`.
- Chạy trên GitHub Pages: Settings → Pages → nhánh `main`, thư mục `/ (root)`.

## Thêm hoặc sửa cây

Mỗi dòng trong biến `R` có dạng:

`Tên VN|Tên khoa học|Họ|Bộ phận dùng|Thành phần 1;Thành phần 2|Công dụng 1;Công dụng 2|Ghi chú`
